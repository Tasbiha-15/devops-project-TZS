## Review turnaround

Every pull request gets a first review **within one working day**. If the author has not heard back by then, they message the team directly.

## Working agreement

- `main` is protected. All changes go through a pull request with one approval.
- Branch from an issue, name the branch after it (for example `fix/3-short-title`), and close the issue from the commit message.
- Reviewers prefix comments with `Blocking:` or `Suggestion:`. Authors answer every comment.
- See [TEAM.md](TEAM.md) for who is responsible for what.
